Use the run_checks tool to run the trusted verification checks on your current changes before you finish: lint, unit, types. With no arguments it runs lint, unit; pass checks to choose a subset. You have at most 3 calls per task, and one call at a time. Results list failing files and lines; fix them and run the checks again. Run tests through this tool rather than through bash. The same checks run again after you finish, so do not weaken or skip tests to make them pass.
